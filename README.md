🎧 Buscador de Audiolibros con Etiquetas
Una aplicación web completa para buscar, organizar y gestionar audiolibros con un avanzado sistema de etiquetas personalizables.

🌟 Características Principales
🔍 Búsqueda Inteligente
Búsqueda manual en múltiples plataformas simultáneamente

Generación automática de enlaces a Z-Library, LibGen, Audible, YouTube, etc.

Tipos de búsqueda específicos: Audiolibros, Torrents o Descargas directas

🏷️ Sistema de Etiquetas Avanzado
Etiquetas predeterminadas con colores asignados (Importante, Normal, Urgente, etc.)

Etiquetas personalizables con cualquier color y nombre

Asignación rápida mediante menús desplegables en cada libro

Filtrado por etiquetas con botones de filtro específicos

Gestor completo para crear, editar y eliminar etiquetas

📊 Gestión y Organización
Marcadores de estado: Descargado / No Encontrado

Estadísticas en tiempo real de tu colección

Ordenamiento automático (libros no encontrados al final)

Interfaz responsive que funciona en todos los dispositivos

💾 Sistema de Backup
Exportación completa de todos los datos (libros, etiquetas, marcadores)

Importación para restaurar o migrar datos

Exportación de lista en formato texto legible

Guardado automático en el navegador

🔄 Conversor de Formatos
Sube un PDF, EPUB, DOCX o TXT arrastrándolo al recuadro del conversor o haciendo clic en él; la página muestra solo las conversiones posibles

Conversiones disponibles: PDF→TXT, PDF→EPUB, EPUB→TXT, EPUB→PDF, DOCX→TXT y TXT→EPUB

Un solo botón "Convertir" descarga el resultado; el archivo no se guarda en la página ni en localStorage

Límite de 50 MB por archivo y barra de progreso con opción de cancelar

Persistencia: la biblioteca sigue en localStorage del mismo origen; actualizar la página no borra los datos. Si aparece una versión anterior tras el despliegue, recarga con Ctrl+F5. Los archivos del conversor nunca se guardan

🚀 Cómo Usar
1. Primera Búsqueda
Ingresa el título del libro en el campo principal

(Opcional) Ingresa el autor para búsquedas más precisas

Haz clic en "Buscar en Todas las Plataformas"

Los resultados aparecerán como tarjetas con todos los enlaces encontrados

2. Gestión de Etiquetas
Crear etiqueta personalizada:

Haz clic en "Gestionar Etiquetas"

Ingresa nombre y selecciona color

Guarda la etiqueta

Asignar etiquetas a un libro:

Haz clic en el indicador circular en la esquina superior derecha de cada tarjeta

Selecciona una etiqueta del menú desplegable

Filtrar por etiquetas:

Usa los botones de colores en la sección de filtros

Filtra por etiqueta específica o por "Sin Etiqueta"

3. Marcadores de Estado
✓ Descargado: Marca libros que ya has descargado

✗ No Encontrado: Marca libros sin resultados

Exclusividad: Un libro no puede estar marcado como ambos

4. Exportación/Importación
📤 Exportar Backup: Guarda TODOS tus datos (libros, etiquetas, marcadores)

📥 Importar Backup: Restaura datos desde un archivo JSON

💾 Exportar Lista: Genera un archivo de texto con tu colección completa

5. Convertir Archivos
Arrastra el archivo al recuadro del panel "Conversor de Formatos" o haz clic para seleccionarlo

Revisa las conversiones disponibles que aparecen según el tipo de archivo

Selecciona el formato de destino y haz clic en "Convertir"

Descarga el archivo resultante cuando termine la barra de progreso

La aplicación almacena en LocalStorage:

librosDescargados: IDs de libros marcados como descargados

librosNoEncontrados: IDs de libros sin resultados

⚠️ Limitaciones
Sin servidor: Datos almacenados solo en el navegador

Sin sincronización: No hay sincronización entre dispositivos

Límite de almacenamiento: Depende del navegador (~5-10MB)

Sin búsqueda en tiempo real: Solo genera enlaces de búsqueda

Conversiones basadas en texto: los PDF escaneados requieren OCR y no se procesan; EPUB→PDF y PDF→EPUB no conservan imágenes ni maquetación

El convertidor necesita servir la página por HTTP(S), por ejemplo con py -m http.server 8000; abrir index.html con file:// puede bloquear PDF.js
